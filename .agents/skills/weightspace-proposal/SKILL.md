# Weight-Space Proposal Skill

Read `AGENTS.md` and `docs/CODEX_APPROVAL.md`. First ensure the developer has installed the local lab. Use `codex/tools/propose.py` to create an **unsigned** patch and `codex/tools/inspect_proposal.py` to explain validation evidence. Report hashes and source commit. Stop before any private key access, signing, actual patch application, or deployment. Those steps belong to a separate human-controlled terminal and trust policy.
