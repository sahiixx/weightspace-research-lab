# Research evidence, scope and claim ledger

Snapshot date: **2026-11-05**. These references may change after packaging.

## Direct primary sources

1. Takehi, Teoh, Zhang and Khattab (MIT CSAIL), "Sparks of Weight-Space Programming: LLMs can natively read & write neural network weights", posted **2026-11-02**: https://rikiyat.github.io/blog/weight-space-programming/
2. Authors' public logs, code and evaluation folders for eight experiments: https://github.com/RikiyaT/lm_understand-logs
3. Detailed Experiment 8 setup, sampling settings, audit record, exact diff and limitations: https://github.com/RikiyaT/lm_understand-logs/blob/main/exp8_math/README.md
4. Released edited Qwen checkpoint, published hashes and re-run: https://huggingface.co/RikiyaT/Qwen3.5-0.8B-weight-space-programming
5. Independent experimental package/replication, which explicitly compares thinking-on and thinking-off inference: https://pypi.org/project/weightspace/

## What the original work reports

- Experiments 1–3: frontier model infers aspects of small trained networks from raw weights.
- Experiment 4: a failing control-policy network receives a direct edit.
- Experiments 5–6: model weights are generated for small game policies and Go.
- Experiment 7: analysis of sycophancy in language-model weights.
- Experiment 8: model edits Qwen3.5-0.8B with *no gradient descent or training*. The reported 50-pass edit targets MLP down-projection output columns in **layers 15 and 19** and changes 131,072 selected weight positions in the proposed operation. After bfloat16 rounding, the official Experiment 8 README states **130,188** positions differ from the base.

Published **original** vs **50-pass edited** results under the researchers' *thinking-enabled* vLLM protocol: MATH-500 7.9% vs 48.1%, GSM8K 13.8% vs 67.1%, IFEval 21.0% vs 62.3%. These are **authors' reported outcomes**, not results generated by this project. These outcomes were affected substantially by the base model repeatedly reaching the 32,768-token generation cap. The released edited checkpoint's model card documents a separate 51.0% MATH-500 re-run, not identical to the paper's reported value.

## Crucial comparison

Independent replication described at https://pypi.org/project/weightspace/ found the original Qwen model achieved 46.4% MATH-500 with *thinking off* under its separate 8k-token protocol, compared with 42.0% for the published edit. Therefore the paper's reported gain **must not be described as evidence that the model gained 40 absolute points of new intrinsic math knowledge under every setting**. It is credible evidence that the patch reduces problematic thinking loops under the specified test setup, not a universal performance improvement.

Do not compare 32k multi-sample thinking-on scores with 8k single-sample thinking-off scores as if they came from the same controlled experiment.

## What this lab provides instead

The testable, offline `wslab` algorithm is *a deliberately simpler engineering exercise* that proves:

1. A PyTorch checkpoint can be inspected and fingerprinted consistently.
2. One selected scalar can be changed without gradient descent and without mutating the original state.
3. Candidate edits can be evaluated on validation data, rejected based on explicit constraints, and scored on an untouched holdout set.
4. A new checkpoint can be verified against an exact patch manifest.

It **does not** independently reproduce a Qwen benchmark, discover causal circuits, operate an LLM-driven weight editing agent, demonstrate zero-shot generation of a new neural network, or prove model self-improvement. Its numeric accuracy scores are *only* for a deterministic toy task.

## Why we didn't call this a production WS-OS

A collection of toy PyTorch scripts, SHA-256 hashes and JSON metadata is not enough to establish a secure, autonomously optimizing, multi-tenant production operating system. Such a deployment would require authenticated checkpoint provenance, robust sandbox isolation, operations security, incident response, tests against prompt injection and model poisoning, audit logs and much broader acceptance benchmarks. No such external deployment is claimed here.
